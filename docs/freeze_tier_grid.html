✅ proven — real build baked it + check_build clean 💥 broke — real build failed the contract · unmeasured — no real build yet (declared row, or Docker down) carried @sha — proven earlier, carried forward unchanged (incremental — not rebuilt this run)

A tier is proven only when a real docker build returned success AND env_honesty.check_build returned no violations — never on a Docker-less run (that would read green while proving nothing). Floors are a reviewed ratchet in scripts/freeze_tiers.py (raised by a human, never by the generator); tests/test_freeze_tier_coverage.py asserts floor ≤ measured and makes an unbacked floor a build failure. Measurement is incremental: --only <tier> rebuilds that tier and CARRIES the rest forward from the committed grid, keeping each carried tier's original measured sha (shown per row) rather than re-stamping it as current — so adding or fixing one tier never forces a full N-tier re-sweep, and a carried tier whose recipe later changes auto-reddens (its recipe_fingerprint no longer matches) until it is re-baked. Regenerate one tier: python scripts/measure_freeze_tier_coverage.py --only <tier>. Real builds can't run in CI, so if a row's measured sha isn't HEAD, re-run it before trusting it.
